# AI Course - Business Entry 101

This repository contains workshop materials and documentation for the "AI Course - Business Entry 101" workshop. The workshop is designed to help business professionals understand and leverage AI technologies in their organizations.

## Contents

- Participant Persona Worksheet
- Website Outline Template
- Wireframe Sketch Sheet
- Prompt Starter Sheet
- Agenda & Talking Points
- Feedback Sheet
- Tech Troubleshooting Cheat Sheet
- Workshop Guide

## Website

The workshop materials are available as a website hosted on GitHub Pages:

**[View Workshop Materials Website](https://manateeit.github.io/ai-course-business-entry-101/)**

The website provides:
- Easy access to all workshop documents in Markdown format
- An embedded PowerPoint presentation viewer
- Simple navigation between different materials

## Repository Structure

- `WORD/` - Contains the original Word documents
- `Markdown/` - Contains the Markdown versions of the documents
- `website/` - Contains the source code for the GitHub Pages website
- `*.pptx` - PowerPoint presentations for the workshop

## Getting Started

These materials are designed to be used in a workshop setting. Each document serves a specific purpose in helping participants understand AI concepts and applications in business contexts.
