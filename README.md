# AI Course - Business Entry 101 Website

This is a simple website to host the workshop materials for the AI Course - Business Entry 101. The website is designed to be hosted on GitHub Pages and provides access to:

- Workshop documents in Markdown format
- PowerPoint presentation viewer
- Easy navigation between different workshop materials

## Features

- Responsive design that works on desktop and mobile devices
- Markdown rendering for workshop documents
- Embedded PowerPoint viewer
- Simple and intuitive navigation

## Structure

- `index.html` - Main entry point for the website
- `css/` - Contains the styling for the website
- `.nojekyll` - Tells GitHub Pages not to process the site with Jekyll

## Hosting

This website is designed to be hosted on GitHub Pages. The site pulls content directly from the GitHub repository, so any updates to the Markdown files or PowerPoint presentations in the repository will be automatically reflected on the website.

## Usage

To view the website locally, simply open the `index.html` file in a web browser.
