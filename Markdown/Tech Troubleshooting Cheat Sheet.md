**Tech Troubleshooting Cheat Sheet**

**Workshop Title**: From Prompt to Publish -- AI Meets Website Creation\
**For Instructors Only**

**💻 ChatGPT Issues**

**Problem:** Can't log in\
**Fix:** Have participant try logging in via Incognito/Private mode. If
using Gmail login, check popup blockers.

**Problem:** Can\'t find Projects tab\
**Fix:** Confirm user is on ChatGPT Pro (GPT-4). Projects are not
available on free-tier.

**Problem:** Chat not responding or freezing\
**Fix:** Refresh page. Clear browser cache. Try a different browser
(Chrome preferred).

**Problem:** File upload not working\
**Fix:** Ensure the participant is in the Project view. Check file
format (PDF, TXT, DOCX supported).

**🌐 Lovable Issues**

**Problem:** Editor not loading\
**Fix:** Check internet connection. Log out and back in. Try on Chrome.

**Problem:** Site won't publish or save\
**Fix:** Confirm account is verified and project is saved. Refresh
browser.

**Problem:** Design blocks acting weird\
**Fix:** Delete block and re-add. Sometimes browser zoom or plugins
interfere.

**🚫 Wi-Fi / Connection Issues**

**Problem:** Can't connect to Wi-Fi\
**Fix:** Ensure correct SSID and password. Move closer to router if
possible. Restart device.

**Problem:** Internet extremely slow\
**Fix:** Have one instructor check bandwidth-heavy apps (YouTube, etc.).
Use mobile hotspot if urgent.

**✉️ General Tips**

-   Keep printed cheat sheets near each station.

-   Use a Slack/WhatsApp thread for instructors to flag issues quietly.

-   Bring a USB with all PDFs in case someone can\'t access Drive.

-   If everything fails, pair the participant with someone temporarily.

**Emergency Backups:**

-   Spare laptop/tablet (if available)

-   Printed version of Brand Guide and Persona Worksheet
